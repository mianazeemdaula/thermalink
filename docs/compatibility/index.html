Expected to work (by standard, not individually tested)

Thermalink emits standard Epson ESC/POS commands (ESC @, ESC a, ESC E, GS !, GS V, ESC p, GS ( k for QR, GS k for barcodes, GS v 0 for raster images). Printers that implement ESC/POS are expected to work. That includes most models from Epson (TM series), Bixolon, Xprinter, Rongta, HPRT, Sewoo, Citizen (ESC/POS mode), and generic 58/80 mm "POS-58 / POS-80" printers.

Exceptions to know about:

  • Star Micronics printers in Star Line Mode need to be switched to ESC/POS emulation (most current Star models support it via their config utility).
  • Some very cheap printers lack native QR support. Use an image QR instead (see TROUBLESHOOTING.md).
  • NIPPON PRIMEX NP-2511 / NP-3511 are not ESC/POS printers (no GS v 0, GS V). Use the printer profile setting "commands": "nippon" (1.0.2+), which sends their own ESC b raster and ESC i / ESC m cuts in image mode. Written from the NP-2511/3511 specification (Ver. 0.07) and covered by automated tests; not yet tested on a real NP-3511.

Label printers

Label printers get your bytes untouched (raw). You write ZPL (Zebra), TSPL (TSC, 4BARCODE, Xprinter label models) or EPL. Samples are in examples/labels/.
