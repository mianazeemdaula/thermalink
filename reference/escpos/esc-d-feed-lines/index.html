ESC/POS command reference › ESC d

ESC d (1B 64) and LF (0A): print and feed paper

Nothing prints until the printer gets a line feed. 0A prints and feeds one line, 1B 64 n prints and feeds n lines.

ASCIIESC d n
Hex1B 64 n
Decimal27 100 n

Parameters

nnumber of lines to feed, 0 to 255. Line height is the current line spacing (see ESC 3).

What it does

Characters wait in a line buffer. LF, ESC d and ESC J print what is in it and move the paper. A job that ends without one of them can leave its last line unprinted.

escpos-php's feed($lines) writes a plain LF for one line and ESC d n for more, with n from 1 to 255. ESC J n feeds by n dots (motion units) instead of lines, for fine spacing.

Thermalink sends ESC d 3 before every cut, so the cutter clears the last printed line.

Example

ESC d 3 prints "Line two" and feeds two more blank lines.

4C 69 6E 65 20 6F 6E 65 0A 4C 69 6E 65 20 74 77 6F 1B 64 03 41 66 74 65 72 20 33 20 6C 69 6E 65 73 0A

Sending it from code

JavaScript (bytes)

const feed = (n) => (n === 1 ? [0x0a] : [0x1b, 0x64, n]);

PHP with escpos-php

$printer->feed(3); // 1B 64 03

Python (raw bytes)

data += b"\x1b\x64\x03"  # print and feed 3 lines

Common mistakes

  • Ending the job with text and no line feed: the last line can stay in the buffer.
  • Cutting straight after the last line. The cutter sits a little past the print head, so feed a few lines first or use GS V 65 n.

Related commands
