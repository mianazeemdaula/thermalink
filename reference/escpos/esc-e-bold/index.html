ESC E (1B 45): bold text on a receipt printer

1B 45 01 turns bold on, 1B 45 00 turns it off. Epson calls it "emphasized" mode.

ASCIIESC E n
Hex1B 45 n
Decimal27 69 n

Parameters

n1 = bold on, 0 = bold off. The viewer reads only the lowest bit.

What it does

Bold stays on until you turn it off with ESC E 0, reset with ESC @, or send an ESC ! byte without bit 3 set. It applies to every character after it, across lines.

escpos-php's setEmphasis(true) writes exactly 1B 45 01, and python-escpos uses the same bytes for bold=True. Thermalink uses it for bold rows on the BIXOLON.

Example

Only the total line is bold.

49 74 65 6D 0A 1B 45 01 54 4F 54 41 4C 20 20 20 20 20 31 32 2E 35 30 0A 1B 45 00 54 68 61 6E 6B 20 79 6F 75 0A

Preview drawn in your browser by the ESC/POS viewer's engine on 80 mm paper. Letters use a similar monospace font, not the printer's own. Open this example in the viewer to edit the bytes.

Sending it from code

JavaScript (bytes)

const boldOn = [0x1b, 0x45, 0x01], boldOff = [0x1b, 0x45, 0x00];

PHP with escpos-php

$printer->setEmphasis(true);  // 1B 45 01
$printer->text("TOTAL     12.50\n");
$printer->setEmphasis(false); // 1B 45 00

Python (raw bytes)

data = b"\x1b\x45\x01" + b"TOTAL     12.50\n" + b"\x1b\x45\x00"

Common mistakes

  • Forgetting ESC E 0: the rest of the receipt, and the next job if it does not start with ESC @, comes out bold.
  • Mixing ESC E with ESC !. ESC ! sets bold through bit 3, so a later ESC ! 0 turns off the bold you set with ESC E.
