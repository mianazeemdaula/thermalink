ESC/POS command reference › ESC !

ESC ! (1B 21): set font, bold, size and underline in one byte

An older command that sets five styles at once from the bits of n. Handy, but it overwrites whatever you set before with the single-purpose commands.

ASCIIESC ! n
Hex1B 21 n
Decimal27 33 n

Parameters

nbit 0 (0x01) font B, bit 3 (0x08) bold, bit 4 (0x10) double height, bit 5 (0x20) double width, bit 7 (0x80) underline. Add the values you want.

What it does

escpos-php's selectPrintMode() takes OR-ed MODE_* constants with exactly these values (FONT_B 1, EMPHASIZED 8, DOUBLE_HEIGHT 16, DOUBLE_WIDTH 32, UNDERLINE 128) and notes that mode 0 "has a similar effect to running initialize()" for text style.

python-escpos uses ESC ! 0x10, 0x20 and 0x30 for its "2h", "2w" and "2x" sizes.

Because every bit is written each time, ESC ! turns off anything whose bit is 0: bold from ESC E, underline from ESC -, and a size from GS !. It only goes up to double size; use GS ! for 3x to 8x.

Example

Four values of n.

1B 21 08 62 6F 6C 64 20 28 30 78 30 38 29 0A 1B 21 30 32 78 20 28 30 78 33 30 29 0A 1B 21 81 66 6F 6E 74 20 42 20 2B 20 75 6E 64 65 72 6C 69 6E 65 20 28 30 78 38 31 29 0A 1B 21 00 61 6C 6C 20 6F 66 66 20 28 30 78 30 30 29 0A

Sending it from code

JavaScript (bytes)

const mode = (n) => [0x1b, 0x21, n];
mode(0x08 | 0x30); // bold, double width and height

PHP with escpos-php

$printer->selectPrintMode(Printer::MODE_EMPHASIZED | Printer::MODE_DOUBLE_WIDTH); // 1B 21 28
$printer->selectPrintMode(); // 1B 21 00

Python (raw bytes)

data = b"\x1b\x21\x38" + b"BIG BOLD\n" + b"\x1b\x21\x00"

Common mistakes

  • Setting bold with ESC E 1, then size with ESC ! 0x30: bold is now off, because bit 3 was 0.
  • Expecting 3x text from ESC !. Its size bits only double.

Related commands

  • GS !: double width and height text, up to 8x
  • ESC E: bold text on a receipt printer
  • ESC -: underline text on a receipt printer
