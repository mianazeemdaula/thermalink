ESC - (1B 2D): underline text on a receipt printer

1B 2D 01 gives a thin (1-dot) underline, 1B 2D 02 a thick (2-dot) one, 1B 2D 00 turns it off.

ASCIIESC - n
Hex1B 2D n
Decimal27 45 n

Parameters

n0 = off, 1 = 1-dot line, 2 = 2-dot line. The viewer also accepts the ASCII digits 0x30 to 0x32.

What it does

The line is drawn under each character, and it stays on until ESC - 0, ESC @, or an ESC ! byte without bit 7.

python-escpos labels the two values "Underline font 1-dot ON" and "2-dot ON". escpos-php has UNDERLINE_NONE, UNDERLINE_SINGLE and UNDERLINE_DOUBLE for 0, 1 and 2. "Double" there means the thicker line, not two lines.

Example

n = 1, then n = 2, then off.

1B 2D 01 54 68 69 6E 20 75 6E 64 65 72 6C 69 6E 65 0A 1B 2D 02 54 68 69 63 6B 20 75 6E 64 65 72 6C 69 6E 65 0A 1B 2D 00 4E 6F 20 75 6E 64 65 72 6C 69 6E 65 0A

Sending it from code

JavaScript (bytes)

const underline = (n) => [0x1b, 0x2d, n]; // 0, 1 or 2

PHP with escpos-php

$printer->setUnderline(Printer::UNDERLINE_SINGLE); // 1B 2D 01
$printer->setUnderline(Printer::UNDERLINE_NONE);   // 1B 2D 00

Python (raw bytes)

data = b"\x1b\x2d\x01" + b"Thin underline\n" + b"\x1b\x2d\x00"

Common mistakes

  • Reading "double underline" as two lines. Value 2 is one thicker line.
  • Leaving underline on before padding spaces for a two-column row, so the gap between name and price gets underlined as well.
