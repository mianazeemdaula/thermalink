ESC t (1B 74): select the code page for accents and the euro sign

Receipt printers do not understand UTF-8. They print one byte per character from a code page, and 1B 74 n picks which one.

ASCIIESC t n
Hex1B 74 n
Decimal27 116 n

Parameters

ncode page number. In Epson numbering: 0 = CP437, 2 = CP850, 16 = Windows-1252, 17 = CP866, 19 = CP858 (CP850 with the euro sign). Numbers differ between brands; the self-test page usually lists them.

What it does

Bytes 0x00 to 0x7F are plain ASCII on every page. Bytes 0x80 to 0xFF depend on n: the same byte can be "é" on one page and a box-drawing line on another. Encode your text with the matching code page before sending it.

UTF-8 uses two or three bytes for each accented letter, so "Café" sent as UTF-8 prints as "Caf├⌐" on CP437. The viewer flags UTF-8 sequences for this reason.

escpos-php's selectCharacterTable() writes ESC t n, except on Star printers, where it writes ESC GS t n instead, so the same number does not work across brands.

A printer in double-byte (Kanji / Chinese) mode ignores this for bytes above 0x80. That happened on my BIXOLON: every probe line printed Chinese characters whatever n was, and the cause was a memory switch. I wrote it up on dev.to.

Example

The euro sign is byte D5 in CP858 (n = 19) but byte 80 in Windows-1252 (n = 16).

1B 74 13 43 50 38 35 38 20 65 75 72 6F 3A 20 D5 20 63 61 66 65 3A 20 63 61 66 82 0A 1B 74 10 57 69 6E 2D 31 32 35 32 20 65 75 72 6F 3A 20 80 0A 1B 74 00

Sending it from code

JavaScript (bytes)

// Encode yourself; TextEncoder only does UTF-8.
const cp858 = { "€": 0xd5, "é": 0x82 };
const bytes = [0x1b, 0x74, 19, ...[..."5 €"].map(c => cp858[c] ?? c.charCodeAt(0))];

PHP with escpos-php

$printer->selectCharacterTable(19); // 1B 74 13 on Epson-style printers

Python (raw bytes)

data = b"\x1b\x74\x13" + "Café 5 €\n".encode("cp858")

Common mistakes

  • Sending UTF-8 text. Encode to the printer's code page (Python has cp437, cp850, cp858 and cp1252 codecs).
  • Taking Epson numbers to another brand. Check the printer's self-test page.
  • Expecting ESC t to fix Chinese characters. That is double-byte mode, set by FS & or a memory switch; FS . cancels the command version.
