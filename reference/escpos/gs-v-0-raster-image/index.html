GS v 0 (1D 76 30): print a logo or image on a receipt printer

The most widely used way to print a logo. You send a small header, then the image as rows of bits: 1 is a black dot, 0 is white.

ASCIIGS v 0 m xL xH yL yH d1...dk
Hex1D 76 30 m xL xH yL yH d1...dk
Decimal29 118 48 m xL xH yL yH d1...dk

Parameters

m0 = normal, 1 = double width, 2 = double height, 3 = both (0x30 to 0x33 also accepted by the viewer).
xL xHwidth in bytes, not dots: xL + xH × 256 = width in dots / 8, rounded up.
yL yHheight in dots: yL + yH × 256.
d1...dkk = width in bytes × height. Rows top to bottom; in each byte the most significant bit is the leftmost dot.

What it does

Convert the image to black and white first (threshold or dithering), pad each row to a multiple of 8 dots, then pack 8 dots per byte. Thermalink does this in its agent and sends one GS v 0 per image, and its output is tested pixel for pixel against the viewer.

The printable width is fixed: commonly 576 dots on 80 mm paper and 384 on 58 mm. A wider image is clipped on the right, not scaled; the viewer warns when an image is too wide.

escpos-php uses GS v 0 for bitImage() (and notes it pads the right side when the width is not a multiple of 8). Its graphics() method uses the newer GS ( L command, which not every printer supports.

Sending it from code

JavaScript (bytes)

// rows: array of Uint8Array, one bit per dot, MSB = leftmost
function raster(rows, widthDots) {
  const xb = Math.ceil(widthDots / 8), h = rows.length;
  return [0x1d, 0x76, 0x30, 0, xb & 255, xb >> 8, h & 255, h >> 8, ...rows.flatMap(r => [...r])];
}

PHP with escpos-php

$logo = EscposImage::load("logo.png");
$printer->bitImage($logo); // GS v 0

Python (raw bytes)

def raster(rows, width_dots):
    xb = (width_dots + 7) // 8
    head = bytes([0x1d, 0x76, 0x30, 0, xb % 256, xb // 256, len(rows) % 256, len(rows) // 256])
    return head + b"".join(rows)

Common mistakes

  • Putting the width in dots into xL xH. It is bytes: a 576-dot-wide image is 48 00.
  • Sending a colour or greyscale image byte per pixel. Each byte is 8 dots.
  • One huge image on a printer with a small buffer. Split tall images into bands of a few hundred rows, each with its own header.
